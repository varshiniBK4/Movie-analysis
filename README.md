# 🎬 Movie Analysis

## 📌 Project Overview

This project uses Python to analyze movie-related data and explore relationships between different features using data analysis, visualization, and machine learning techniques.

## 🛠️ Technologies Used

* Python
* Pandas
* Matplotlib
* Scikit-learn
* Jupyter Notebook

## 🔍 Project Workflow

* Data preprocessing and cleaning
* Feature encoding and preparation
* Mutual information analysis to examine feature relationships
* Data visualization
* Linear Regression model training

## 📊 Feature Analysis

Mutual information is used to estimate the relationship between selected features, including Year, Category, Language, and Region, and the target variable.

## 🤖 Machine Learning

A Linear Regression model is trained to explore the relationship between the selected input features and the target variable.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Install the required Python libraries.
3. Open the `.ipynb` file in Jupyter Notebook.
4. Run the notebook cells in order.
